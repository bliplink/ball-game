# Velvet Break

一个纯 `HTML + CSS + JavaScript` 的同屏双人美式 8 球小游戏。

## 打开方式

直接双击 [index.html](./index.html) 即可运行。

如果你更喜欢本地服务，也可以在当前目录执行：

```powershell
python -m http.server 5501
```

然后打开 `http://localhost:5501`

## 规则

- 两名玩家共用一台设备轮流出杆
- 开球后属于开放球台，先合法进球的一方获得实色或花色
- 合法打进自己的球可继续出杆
- 犯规则对手获得自由球，可在台面任意合法位置摆放白球
- 清完本组后才能攻击 8 号球
- 提前打进 8 号球，或在 8 号球回合犯规，直接判负

## 操作

- 鼠标拖动白球后方蓄力，松手出杆
- 自由球状态下，先点击合法位置摆放白球
- `R` 重新摆当前局
- `N` 开下一局并轮换开球方
